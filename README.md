# lab1-os-info
# Лабораторная работа №1. Определение ОС и сбор её параметров

## Что делает скрипт

Файл `my_script.py`:

1. Определяет, в какой ОС он запущен — **Windows** или **Linux**
2. Собирает несколько основных параметров этой ОС.
3. Сохраняет результат в файл `os_info.json` рядом со скриптом.

## Как запустить

```bash
python my_script.py
```

## Какие библиотеки используются и зачем

Все модули - встроенные в Python.

| Модуль | Зачем нужен |
|---|---|
| `platform` | узнать название ОС, её версию, архитектуру процессора, имя компьютера |
| `os` | узнать имя пользователя (через переменные окружения) |
| `shutil` | узнать объём свободного места на диске |
| `json` | записать собранные данные в файл в формате JSON |
| `datetime` | записать время запуска скрипта |

## Собираемые параметры

| Параметр в JSON | Что это |
|---|---|
| `os_name` | название ОС (Windows / Linux / macOS) |
| `os_version` | версия/релиз ОС |
| `architecture` | архитектура процессора (например, x86_64) |
| `hostname` | имя компьютера |
| `username` | имя текущего пользователя |
| `free_disk_gb` | свободное место на диске (в гигабайтах) |
| `started_at` | дата и время запуска скрипта (UTC) |
